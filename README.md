# Hospital Emergency Waiting-Time Optimization System

## Project Overview
This project analyzes hospital emergency department waiting times using Power BI. It aims to understand patient arrivals, waiting times, hospital occupancy, and resource availability through an interactive dashboard.

## Objectives
- Analyze patient waiting times.
- Understand patient arrivals by hour.
- Study the impact of doctor availability on waiting time.
- Analyze hospital occupancy rates.
- Compare admitted and discharged patients.
- Identify factors associated with longer waiting times.

## Tools and Technologies
- Power BI
- Power Query
- DAX
- CSV Dataset

## Dataset Information
The project uses a synthetic dataset containing 2,000 patient records.

The dataset includes:
- Patient ID
- Arrival Hour
- Triage Level
- Doctors Available
- Nurses Available
- Patients Waiting
- Occupancy Rate
- Treatment Time
- Admission Status
- Waiting Time

**Note:** The dataset is simulated for educational and project demonstration purposes. It does not represent actual hospital performance.

## Key Dashboard Insights
- Total Patients: 2,000
- Average Waiting Time: 49.88 minutes
- Maximum Waiting Time: 110.27 minutes
- Average Treatment Time: 65.05 minutes
- Average Occupancy Rate: 69.52
- Admitted Patients: 982
- Discharged Patients: 1,018
